# Featured project review

Reviewed on 11 September 2026. Implemented after approval: Wire leads the preview, with skillctl and Durable Researcher on the homepage and Linkripper also featured on Projects.

The sync migration preserved the old selection. This review considers newer personal repositories and all 28 public repositories in Steel Experiments. Read descriptions, README status sections, and contribution history. No project runtime tests were run.

## Recommended selection

| Placement | Repository | Editorial reason |
| --- | --- | --- |
| Lead feature | [Wire](https://github.com/steel-experiments/wire) | A clear progression from a browser objective to a recorded run and a reusable script. Strong fit for the site's focus on agent tools and evidence. |
| Feature | [skillctl](https://github.com/nibzard/skillctl) | A practical developer tool with installation, updates, diagnostics, and published release instructions. |
| Feature | [Durable Researcher](https://github.com/steel-experiments/durable-researcher) | A research agent with persisted progress, resume operations, and sourced reports. Shows substantive systems work. |
| Visual project feature | [Linkripper](https://github.com/steel-experiments/linkripper) | An understandable web archive with page captures, screenshots, and a browsing interface. Strong candidate for a real product screenshot. |

Keep AgentProbe available as a project and article, but move it below the new lead selection. Keep small utilities in the directory.

## Additional strong candidates

- [OpenAPI Agent Lab](https://github.com/nibzard/openapi-agent-lab): local deterministic mocks and evaluations. Its README explicitly says the hosted service is not built.
- [Pi Steel](https://github.com/steel-dev/pi-steel): the official integration has graduated from the experiments organization. Use the new canonical repository and acknowledge shared contributions.
- [Internal Agents Map](https://github.com/steel-experiments/internal-agents-map): useful evidence of research and industry analysis alongside software projects.
- [AgentLab](https://github.com/nibzard/agentlab): substantial infrastructure work, though its Proxmox setup makes it less immediately approachable.
